👁️ VisionGuard – Eye Health Monitoring App

📱 Overview

 Vision Guard is a smart eye health monitoring mobile application designed to help users protect their eyesight during long screen usage.
The app tracks eye strain indicators, posture, screen distance, and redness to promote healthier digital habits.


 ✨ Key Features

* 👀 Eye Distance Monitoring
* 🔴 Eye Redness Detection
* ⏰ Smart Break Alerts
* 🪑 Posture Guidance
* 📊 Eye Health Reports & Analytics
* 🔔 Real-time Notifications
* 📱 User-friendly Interface


 🧠 Problem Statement

In today’s digital world, people spend long hours on screens which leads to:

* Eye strain
* Dry eyes
* Poor posture
* Vision problems

VisionGuard aims to reduce these issues by providing real-time monitoring and alerts.



 🛠️ Tech Stack

* **Language:** Kotlin / Java
* **Platform:** Android Studio
* **UI:** XML (Android UI Design)
* **Version Control:** Git & GitHub
* **Optional Integration:** Health APIs (Future Scope)


 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/anjalipaliwal52-svg/VisionGuard.git
   ```
2. Open the project in **Android Studio**
3. Sync Gradle
4. Connect an Android device or emulator
5. Click ▶️ Run
